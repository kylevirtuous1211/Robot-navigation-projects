# Final Project — TA Q&A (rules & constraints)

Key questions answered by the TA. These define the grading/demo constraints for the
Final Project.

## Key takeaways

- **No task ordering** — Task 1/2/3 can be done in any order; only completion matters.
- **One session for all tasks** — every task must be completed within the *same* session;
  the highest score is taken.
- **Difficulty doesn't affect scoring** — use **Easy** (it provides LiDAR, Depth Map, and RGB).
- **Off-road allowed** — the robot does not have to stay on the road.
- **Scoring** — see Canva slides p.108–109. Pick one map to demo; each map has its own
  Final Project high score. Scores are timestamped on the server, and ranking uses the
  server-recorded time the score was achieved.
- **Unity passed but server marked fail** — record a video as proof and discuss with the TA.

## Full Q&A

**Q1：完成任務是否有順序限制？例如 Task 1 → Task 2 → Task 3？**
A1：沒有。只要所有任務都有完成，任務順序不限。

**Q2：每個任務需要在同一個 session 完成，還是可以在不同 session 完成？**
A2：所有任務必須在同一個 session 內完成。最終會採計最高分。

**Q3：選單中的難度設定會影響評分嗎？**
A3：不會。建議使用 Easy 難度，因為 Easy 難度會提供 LiDAR、Depth Map 和 RGB 資訊。

**Q4：Final Project 中，機器人一定要沿著道路走嗎？**
A4：不需要。可以離開道路行走。

**Q5：表現分數是如何計算的？**
A5：請參考 Canva 投影片第 108 和 109 頁：
https://canva.link/l1rj3yv0og2kwla

Demo 時請選擇其中一張地圖進行展示。每張地圖都有各自的 Final Project 最高分。
由於分數會更新到 server 上，我們可以從 server 查看取得分數的確切時間，並以此作為排名依據。

**Q6：如果 Unity 任務已經完成，但 server 自動判定失敗怎麼辦？**
A6：如果擔心發生這種情況，可以錄影作為證明，之後再與助教進一步討論。
